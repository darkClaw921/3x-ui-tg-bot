# app/xui/clients.py

Операции над клиентами через НОВЫЙ email-keyed API /panel/api/clients/* (React-rewrite 3x-ui). Клиенты по email, не UUID. add_client: POST /panel/api/clients/add тело {client:{email,uuid,subId,flow,totalGB,limitIp,tgId,enable,reset,expiryTime,comment}, inboundIds:[id]} (без старой settings-строки). get_client: GET /panel/api/clients/get/:email → obj.client или {}. update_client(client, email, **fields): read-merge-write — читает get_client, накладывает fields, постит весь объект в POST /panel/api/clients/update/:email (ПОЛНАЯ замена, email обязателен, числовой id выбрасывается т.к. API ждёт id строкой). Сохраняет нетронутые поля (totalGB/subId) — revoke/extend не сбрасывают квоту. del_client(client, email, keep_traffic=False): POST /panel/api/clients/del/:email[?keepTraffic=1], soft-fail not found. get_client_traffics(client, email): трафик в пагинированном списке GET /panel/api/clients/list/paged?search=:email → items[].traffic{up,down,total,expiryTime,enable}. Helpers make_client_uuid/make_client_email/_make_sub_id/_q(url-encode)/_coerce_tg_id. Старый /panel/api/inbounds/*Client* мёртв (404). Вызывающие update/del передают sub.xui_client_email.
