# app/xui/client.py

Базовый async HTTP-клиент 3x-ui (httpx). НОВОЕ: CSRF-bootstrap для React-rewrite версии панели. login() сначала вызывает _bootstrap_session() — GET / корня панели, захват session-cookie + CSRF-токена из <meta name=csrf-token> (regex _CSRF_META_RE) в self._csrf_token; затем POST /login с form-data + заголовком X-CSRF-Token. Без токена новая панель отвечает 403; старые панели без meta → токен None (cookie-only, обратная совместимость). _csrf_headers() мержит X-CSRF-Token во все запросы (request() добавляет на каждый вызов, на retry — свежий после relogin). _needs_relogin теперь триггерит на 401 И 403 (протухший CSRF). request_json распаковывает {success,msg,obj}. Singleton get_xui_client/close_xui_client.
