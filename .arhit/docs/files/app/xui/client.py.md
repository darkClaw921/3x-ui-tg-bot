# app/xui/client.py

XuiClient — async REST-клиент 3x-ui панели на httpx.AsyncClient. Авторизация: POST /login с form data {username,password}, сессионная cookie хранится в httpx cookie jar. Re-login: serialised через asyncio.Lock; вызывается лениво при первом запросе и автоматически при 401 либо при envelope success=false с msg, содержащим 'login'/'session'/'unauthor'. Методы: login(), request(method, path, **kwargs)->httpx.Response (auto-login + 1 retry), request_json(method, path, **kwargs)->Any (раскрывает obj envelope, кидает XuiError), close(), __aenter__/__aexit__. Внутренний _parse распаковывает {success,msg,obj}-envelope. Singleton: get_xui_client()/close_xui_client() с asyncio.Lock-инициализацией. XuiError(RuntimeError) — единая доменная ошибка для всех проблем (HTTP, JSON, success=false). Timeouts: connect=10s, read=30s, write=30s, pool=10s. verify_ssl читается из settings.XUI_VERIFY_SSL (default True). Зависимости: httpx, loguru, app.config.settings (XUI_BASE_URL/USERNAME/PASSWORD/VERIFY_SSL).
