# app/db/repos/subscriptions.py

Репозиторий подписок + traffic_snapshots + subscription_notifications. Литералы: SubscriptionStatus = Literal['active','expired','revoked'], NotificationKind = Literal['3d','1d','0d','expired']. Helpers _to_iso(value)/_utcnow_iso(). Dataclasses Subscription/TrafficSnapshot. Функции: create, get, get_active_for_user (active+expires_at>now), list_for_user, extend, set_status, list_expired_active (active+expires_at<=now — для expire-job), list_active, list_expiring_in(days) (окно (now, now+days]), add_traffic_snapshot, last_traffic_snapshot, try_mark_notification_sent(conn, sub_id, kind) -> bool (INSERT OR IGNORE в subscription_notifications с UNIQUE(sub_id,kind) — возвращает True если запись вставлена, False если уже существовала; используется scheduler-job-ами для дедупликации напоминаний).
