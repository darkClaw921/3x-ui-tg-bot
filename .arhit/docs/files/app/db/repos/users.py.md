# app/db/repos/users.py

Repo таблицы users. Dataclass User теперь содержит поле lang (str, дефолт 'ru', объявлено последним чтобы позиционные User(...) в тестах не ломались); from_row терпит row без колонки lang. Функции: get_by_tg_id/get_by_id/get_by_username (SELECT включает lang), create(..., language_code=None) и get_or_create(..., language_code=None) - нормализуют Telegram language_code через resolve_lang при создании НОВОГО юзера (существующим lang не перетирают), list_all_tg_ids, set_admin, set_lang(conn,user_id,lang) - сохраняет язык (resolve_lang защитно), get_lang(conn,user_id) - читает язык (DEFAULT_LANG если юзера нет).
