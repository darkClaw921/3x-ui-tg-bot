# app/services/wallet.py

Сервис app.services.wallet — слой бизнес-логики над app.db.repos.wallet для баланса в Stars. credit(conn,user_id,amount,*,type,ref=None)->bool: начисляет +amount (через wallet_repo.add), False при дубле ref (идемпотентность top-up/реферал-бонусов), ValueError при amount<=0. try_spend(conn,user_id,amount,*,ref)->bool: атомарное списание под app.db.engine.transaction (BEGIN IMMEDIATE) — пересчёт баланса + raw INSERT 'spend' с amount=-amount внутри одной транзакции (не использует wallet_repo.add, т.к. тот коммитит сам и сломал бы границы транзакции). False при нехватке баланса (overdraw) ИЛИ дубле ref (replay, IntegrityError ловится снаружи transaction). BEGIN IMMEDIATE сериализует писателей -> защита от double-spend; детерминированный ref -> защита от replay. ref обязателен. ValueError при amount<=0.
