# app/services/referrals.py

Сервис реферальной программы. parse_ref_arg(arg) — извлекает tg_id из ref_<tg_id> (None при невалидном). register_referral(conn, *, referrer_tg_id, referred) — bind invitee к inviter: защита self-referral (referrer.id==referred.id), unknown-inviter, привязка только если get_by_referred is None (первый /start побеждает); под капотом create_pending INSERT OR IGNORE. reward_referrer_after_first_payment(conn, bot, *, referred) — после первого платежа: skip если REFERRAL_BONUS_STARS=0, try_mark_rewarded (атомарно раз) → wallet.credit(referrer_id, bonus, type='referral_bonus', ref=f'referral:{referred_id}') + DM пригласившему (best-effort). Двойная идемпотентность: guarded UPDATE + UNIQUE wallet ref. Вызов награды в buy.on_successful_payment (Step 6b, best-effort).
