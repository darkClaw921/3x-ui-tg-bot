# app/services/promos.py

Бизнес-логика промокодов. validate(conn, code, user_id, plan) -> PromoValidation: проверяет код существует (regex case-insensitive через get_by_code), не истёк (expires_at > now), capacity (used_count < max_uses или max_uses=0), пользователь ещё не активировал (one-per-user через promo_redemptions). Когда plan=None — допустимо для standalone-флоу (caller проверит type сам). compute_discount(plan, promo) -> DiscountResult(final_price, extra_days): pure-функция. percent: ceil(price*(100-value)/100), нижний пол 0; flat_stars: max(0, price-value); free_days: final_price=price, extra_days=promo.value. apply(conn, promo_id, user_id, sub_id): обёртка над promos_repo.try_redeem — атомарный инкремент used_count + INSERT в promo_redemptions под BEGIN IMMEDIATE.
