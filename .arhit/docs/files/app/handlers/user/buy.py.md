# app/handlers/user/buy.py

Платёжный флоу: callback handlers cb_open (BuyCB action=open) показывает plans_kb из plans_repo.list_active; cb_pick_plan (action=plan) сохраняет plan_id в FSM, сохраняет promo_id если был, рендерит confirm_kb; cb_apply_promo (action=apply_promo) переводит в BuyFlow.entering_promo; msg_promo_code (msg в entering_promo) вызывает promos_service.validate, на success сохраняет promo_id и рендерит итоговую цену; cb_confirm (action=confirm) рев-валидирует и вызывает billing.send_invoice, очищает FSM. Stateless handlers: on_pre_checkout — parse_invoice_payload, проверяет plan.is_active и promo (срок/capacity), answer_pre_checkout_query; on_successful_payment (F.successful_payment) — идемпотентен по telegram_payment_charge_id, парсит payload, subs_service.create_or_extend (xui-first), payments_repo.create, promos.apply, deliver_keys. При XuiError платёж всё равно записывается, чтобы админ мог починить вручную; пользователь получает уведомление.
