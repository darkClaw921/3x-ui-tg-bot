# app/handlers/user/my_subscription.py

Экран «Моя подписка» для пользователя. Хендлеры на user_router: cb_open_my (UserCB area=my) рендерит карточку подписки со статусом, датой истечения, днями до истечения и live-трафиком из 3x-ui (через xui.clients.get_client_traffics); cb_resend_keys (SubCB action=keys) повторно отдаёт vless+QR+Subscription URL через shared helper _keys.deliver_keys с проверкой ownership (sub.user_id == user.id). Helpers: _format_bytes (human-readable байты с бинарным шагом 1024 — B/KB/MB/GB/TB), _parse_iso/_days_delta (UTC-aware, floor-делением), _is_active (status='active' AND expires_at>now), _format_status_line (статус), _format_days_line (истекает через N дн./истекла N дн. назад), _fetch_traffics (ловит XuiError и любые исключения — экран не падает при недоступной панели), _format_sub_card (HTML-карточка), _sub_card_kb (кнопки получить ключ/продлить/в меню), _no_subscription_kb (купить/в меню). Branches в cb_open_my: нет подписок -> экран 'купите тариф'; одна подписка -> карточка; несколько -> карточка primary (свежайшая активная, или свежайшая по created_at) + компактный список остальных до 5 шт. Кнопка 'Продлить' (BuyCB action=open) появляется только для истёкших/отозванных. Регистрируется в app/handlers/user/__init__.py между menu и buy.
