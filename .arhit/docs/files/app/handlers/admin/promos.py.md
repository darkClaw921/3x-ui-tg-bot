# app/handlers/admin/promos.py

Хэндлеры CRUD промокодов. router = Router(name='admin_promos'). Helpers: _TYPE_LABELS — RU-метки для percent/flat_stars/free_days; _format_promo(promo) — HTML карточка со статусом (активен/исчерпан/истёк); _list_all_promos(conn) — inline SQL (репо не имеет list_all); _promo_is_active(promo); _show_card; _show_list; _parse_expires_at(raw) — принимает '-'/skip/нет/no→None, иначе datetime.strptime('%Y-%m-%d')→ISO UTC 23:59:59, False на ошибку. Callbacks: cb_list/cb_card/cb_deactivate. cb_redemptions показывает историю активаций с tg_id + датой + sub_id. Wizard PromoCreate: cb_create→st_code (уникальность через get_by_code, без пробелов) → cb_type (PromoCB.action=type, field=percent|flat_stars|free_days) → st_value (percent 1..100, flat_stars/free_days >0) → st_max_uses (≥0, 0=∞) → st_expires_at (parse + promos_repo.create с created_by=user.id). На IntegrityError при create — fallback с сообщением.
