# app/handlers/admin/plans.py

Хэндлеры CRUD тарифов. router = Router(name='admin_plans'). Helpers: _format_plan(plan) — HTML карточка; _show_card(message, plan_id, edit=True); _show_list(message, edit=True) — list_all + сортировка active→inactive. Callbacks: cb_list (PlanCB.action=list, clear state) — _show_list; cb_card (action=card) — _show_card; cb_edit_menu (action=edit_menu) — plan_edit_fields_kb; cb_deactivate (action=deactivate) — plans_repo.deactivate + re-render. Wizard PlanCreate (cb_create→st_title→st_days→st_price): валидация days>0, price_stars>=0, на ошибке re-ask без сброса FSM; в конце plans_repo.create + карточка. Wizard PlanEdit (cb_edit (PlanCB.field in title/days/price_stars) → st_edit_value): валидация по типу поля, plans_repo.update, LookupError на отсутствующий plan_id. _FIELD_LABELS — словарь подсказок для редактирования.
