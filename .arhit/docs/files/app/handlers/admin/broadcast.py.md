# app/handlers/admin/broadcast.py

Админский хендлер рассылки поста всем пользователям. FSM BroadcastCreate (waiting_post -> confirming). Router 'admin_broadcast' под admin_router (gated AdminOnlyMiddleware). Хендлеры: cb_open (AdminCB area=broadcast action=open) — вход из главного меню, set_state(waiting_post) + edit_text приглашения с cancel_kb. st_post (state waiting_post, любое сообщение) — сохраняет в FSM post_chat_id/post_message_id (сообщение не разбирается, копируется позже verbatim), считает аудиторию users_repo.list_all_tg_ids, переход в confirming, answer экраном broadcast_confirm_kb. cb_send (state confirming, AdminCB area=broadcast action=send) — answer callback, edit 'Рассылка запущена', вызов services.broadcast.broadcast_message, clear state, edit в сводку (получатели/доставлено/заблокировали/ошибки) + back_to_main_kb; при отсутствии post_* в FSM — alert + сброс. _plural(n) — дательное окончание пользовател-(ю/ям). Отмена — общий cancel_fsm из menu.py.
