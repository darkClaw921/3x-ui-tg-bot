Изменение поведения инлайн-кнопок в админских мастерах тарифов и промокодов: callback-обработчики теперь редактируют исходное сообщение (edit_text) вместо отправки нового (answer). Затронуты: app/handlers/admin/plans.py (cb_plan_preset, cb_plan_manual, cb_inbounds_done, helpers _enter_inbounds_step/_finalize_plan_create получили параметр edit) и app/handlers/admin/promos.py (cb_promo_preset, cb_promo_manual, helper _finalize_promo_create получил параметр edit). Паттерн: helper-функции, вызываемые и из callback (инлайн-кнопка → edit=True → edit_text), и из text-input хендлеров (st_* → edit=False → answer, т.к. сообщение пользователя редактировать нельзя), используют send = message.edit_text if edit else message.answer. Текстовый ввод (st_traffic_gb, st_expires_at, msg_*) и доставка ключей/инвойсов остаются новыми сообщениями. Остальные хендлеры (buy, promo, my_subscription, menu, users, stats, help) уже использовали edit_text.
