Миграция бота на новый REST API панели 3x-ui (мажорный апдейт, React/antd/axios фронтенд). Изменения: (1) app/xui/client.py — CSRF-bootstrap (GET / → meta csrf-token + cookie, заголовок X-CSRF-Token на login и все запросы, relogin на 401/403). (2) app/xui/clients.py — полностью переписан под /panel/api/clients/* (add с {client,inboundIds}; get/update/del по email; update = read-merge-write полная замена без числового id; трафик через clients/list/paged?search). (3) call sites: subscriptions.revoke/extend и scheduler disable теперь update_client(email=sub.xui_client_email); smoke del_client(email). Inbounds API (list/get) без изменений. Проверено smoke-тестом против живой панели (полный цикл login→list→get→add→traffics→del проходит) + 620 unit-тестов. Спецификация API: [[reference-3xui-new-api]].
