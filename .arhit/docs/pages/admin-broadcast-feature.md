Фича админской рассылки постов. Админ -> главное меню -> '📣 Рассылка' -> присылает любой пост (текст/фото/видео) -> подтверждение с счётчиком аудитории -> бот копирует пост всем зарегистрированным пользователям через bot.copy_message и показывает сводку доставки. Затронутые файлы: app/db/repos/users.py (list_all_tg_ids), app/states/admin.py (BroadcastCreate: waiting_post/confirming), app/keyboards/admin.py (кнопка '📣 Рассылка' в admin_main_menu, broadcast_confirm_kb, AdminCB area=broadcast action=send), app/services/broadcast.py (broadcast_message + BroadcastResult, обработка blocked/failed/RetryAfter + throttle), app/handlers/admin/broadcast.py (cb_open/st_post/cb_send), app/handlers/admin/__init__.py (регистрация router). Доставка verbatim через copy_message поддерживает любой тип сообщения без парсинга. Тесты: test_services_broadcast.py, test_handlers_admin_broadcast.py, test_db_users.py (list_all_tg_ids), test_handlers_admin_routing.py (broadcast_confirm_kb).
