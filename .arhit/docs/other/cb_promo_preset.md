# cb_promo_preset

Callback-обработчик кнопки-пресета на шагах мастера промокодов (value/max_uses/expires). Записывает значение в FSM и редактирует текущее сообщение через edit_text для перехода к следующему шагу (раньше answer). На терминальном шаге expires передаёт edit=True в _finalize_promo_create, чтобы карточка созданного промокода отрисовывалась редактированием сообщения. Инлайн-кнопки не создают новых сообщений.
