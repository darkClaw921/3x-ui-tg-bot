# app/xui/clients.py::make_client_email

Generate unique client email label for 3x-ui panel. Signature: make_client_email(tg_id: int, username: str | None = None) -> str. Logic: appends 3-byte hex suffix for uniqueness across re-subscriptions. When username provided, normalizes via re.sub(r'[^A-Za-z0-9_]', '_', username).strip('_').lower()[:32] and prepends as <safe>_tg_<id>_<hex>. Falls back to legacy tg_<id>_<hex> when username is None or normalizes to empty (all special chars). 3x-ui requires email field uniqueness across inbound — the random suffix prevents collisions with stale traffic snapshots after del+re-add cycles. Examples: make_client_email(42) -> tg_42_a1b2c3; make_client_email(42, 'Alice') -> alice_tg_42_a1b2c3; make_client_email(42, 'a.b-c d') -> a_b_c_d_tg_42_a1b2c3; make_client_email(42, '...') -> tg_42_a1b2c3 (fallback).
