# app/handlers/user/promo.py::cb_pick_action_extend_promo

Callback handler bound to (PromoActivate.choosing_action, PromoActCB(action='extend')). User picked '🔄 Продлить #N' on the free-days action screen. Steps: (1) user-presence check; (2) validate sub_id from callback; (3) load promo_id from FSM (session-expired if missing); (4) load subscription via subs_repo.get and verify ownership (user_id match) + status='active' — defensive guard against stale keyboards or crafted callbacks; (5) delegate to _activate_promo_for_sub helper with extend_sub_id=sub.id and inbound_id=sub.xui_inbound_id (inherited from the existing sub — the inbound is NOT chosen anew, and the allow-list check is skipped since an existing sub may live on an inbound that is no longer attached to any plan). The helper re-validates the promo (race guard), calls subs_service.activate_free_days, best-effort promos_service.apply, delivers keys with a '<promo> применён к подписке #<id>' header, clears the FSM.
