# app/handlers/user/promo.py::_activate_promo_for_sub

Internal helper shared by cb_pick_action_extend_promo (and reusable by other paths that need to activate a free-days promo against a specific sub_id without going through the inbound-selection step). Signature: _activate_promo_for_sub(callback, state, bot, user, promo_id, extend_sub_id: int|None, inbound_id). Re-validates the promo via promos_service.validate (race guard — admin may invalidate / another tab may redeem between action-screen and click), verifies promo.type=='free_days' (defence-in-depth), calls subs_service.activate_free_days with the supplied extend_sub_id, best-effort applies the promo via promos_service.apply (race here is acceptable — subscription is already created), delivers keys with an appropriate header ('применён к подписке #N' for extend, 'активирован' for new), clears the FSM. On XuiError during provisioning the promo is NOT redeemed so the user can retry once the panel is back.
