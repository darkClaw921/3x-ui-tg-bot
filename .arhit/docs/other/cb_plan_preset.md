# cb_plan_preset

Callback-обработчик нажатия кнопки-пресета на числовых шагах мастера создания тарифа (days/price/gb). Записывает выбранное значение в FSM-данные и редактирует текущее сообщение через edit_text для перехода к следующему шагу (раньше отправлял новое сообщение через answer). На шаге gb передаёт edit=True в _enter_inbounds_step, чтобы мульти-селект подключений тоже отрисовывался редактированием. Инлайн-кнопки больше не плодят новые сообщения в чате.
