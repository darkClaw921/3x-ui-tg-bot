# cb_plan_manual

Callback-обработчик кнопки «ввести вручную» на шагах мастера тарифа. Редактирует текущее сообщение через edit_text (вместо answer), показывая prompt с cancel_kb. Состояние FSM не меняется — пользователь уже в нужном waiting_* состоянии. Инлайн-кнопка редактирует сообщение, а не отправляет новое.
