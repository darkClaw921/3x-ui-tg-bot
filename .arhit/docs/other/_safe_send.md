# _safe_send

app/scheduler.py — отправляет сообщение пользователю, проглатывая TelegramAPIError (юзер мог заблокировать бота/удалить чат). Параметры: bot, tg_id, text, reply_markup: InlineKeyboardMarkup|None=None (опциональная inline-клавиатура для кнопки 'Продлить' и алертов Ф4; при None — без клавиатуры, существующие вызовы не меняются). Любая ошибка только логируется.
