# E2E чек-лист

Ручной прогон сквозных сценариев на **staging-инстансе 3x-ui** и
**dev-аккаунте Telegram-бота** (Stars test mode).

Чек-лист охватывает все пользовательские и админские флоу из плана и должен
проходиться целиком перед промо-релизом, а также после изменений в
`services.subscriptions`, `services.billing`, `xui/*`, `handlers/user/buy`,
`handlers/admin/*`, `scheduler.py`.

## Подготовка

- [ ] На staging-сервере развёрнута панель 3x-ui с тестовым inbound'ом (VLESS),
      создан тестовый домен/IP, есть валидный TLS-сертификат (или
      `XUI_VERIFY_SSL=false` для self-signed).
- [ ] Бот развёрнут (см. [README → Деплой](../README.md#деплой-systemd))
      или запущен локально, `.env` указывает на staging-панель.
- [ ] В `.env` `ADMIN_IDS` содержит Telegram-ID администратора и НЕ содержит
      Telegram-ID тестового пользователя.
- [ ] У тестового пользователя есть второй Telegram-аккаунт с включёнными
      Stars (test mode) и установлен XRay-клиент (v2rayN / v2rayNG /
      Streisand / Hiddify и т.п.).
- [ ] База `data/bot.db` чистая (или сделан бэкап).
- [ ] Логи открыты в отдельном окне: `journalctl -u tg-vpn-bot -f`
      (или `python -m app.main` для локального запуска).

## Админ-флоу

### 1. Старт под админом

- [ ] От **админ-аккаунта** отправить `/start`.
- [ ] Получено приветствие, видно админ-меню (кнопки «Тарифы», «Промокоды»,
      «Пользователи», «Статистика»).

### 2. Создание тарифа

- [ ] Админ-меню → **Тарифы** → создать тариф (FSM):
  - название: `Test-30d`,
  - цена: `50` (Stars),
  - длительность: `30` дней,
  - трафик-лимит: `10` ГБ.
- [ ] Тариф появился в списке и помечен `active`.

### 3. Создание промокодов

- [ ] Создать `percent`-промокод: код `TEST10`, скидка `10%`, лимит `5`.
- [ ] Создать `flat_stars`-промокод: код `TESTFLAT`, скидка `20` Stars, лимит `5`.
- [ ] Создать `free_days`-промокод: код `TESTFREE`, бонус `7` дней, лимит `5`.

## Пользовательский флоу

### 4. Старт под пользователем

- [ ] Со **второго аккаунта** отправить `/start` → попадание в user-меню
      («Купить подписку», «Моя подписка», «Активировать промокод», «Помощь»).

### 5. Покупка тарифа

- [ ] «Купить подписку» → выбрать `Test-30d` → подтвердить без промокода →
      оплатить Stars (test mode).
- [ ] После `successful_payment` бот пришёл:
  - `vless://`-ссылку,
  - QR-код,
  - Subscription URL.
- [ ] В админ-меню → «Пользователи» → найден этот юзер, подписка отображается.

### 6. Подключение через XRay-клиент

- [ ] Импортировать `vless://` в XRay-клиент.
- [ ] Установить соединение, проверить через `https://2ip.ru` или
      `curl -s ifconfig.me` — внешний IP совпадает с IP staging-сервера.
- [ ] Проверить ping до публичного хоста (`ping <XUI_SERVER_HOST>`).

### 7. Рост трафика

- [ ] Под открытым VPN-соединением скачать любой средний файл (≥10–50 МБ)
      или открыть несколько сайтов в течение 5–10 минут.
- [ ] В админ-меню «Пользователи» → карточка юзера: значения `up`/`down`
      выросли по сравнению с предыдущим шагом.
- [ ] (Опционально) Запросить `GET /panel/api/inbounds/getClientTraffics/<email>`
      напрямую — числа совпадают с тем, что показал бот.

### 8. Покупка со скидкой (percent)

- [ ] Купить ещё один тариф (или продление) с промокодом `TEST10`.
- [ ] Итоговая сумма Stars-invoice = `базовая цена × 0.9` (с округлением
      по правилам `services.billing.compute_discount`).
- [ ] После оплаты в БД у промокода `TEST10` поле `used_count` увеличилось на 1.

### 9. Покупка со скидкой (flat_stars)

- [ ] Купить тариф с промокодом `TESTFLAT`.
- [ ] Итоговая сумма = `базовая цена − 20` (но не ниже минимально допустимой).
- [ ] `used_count` `TESTFLAT` увеличился.

### 10. Активация `free_days`

- [ ] Меню → «Активировать промокод» → ввести `TESTFREE`.
- [ ] Бот сообщил, что подписка продлена на 7 дней.
- [ ] «Моя подписка»: `expires_at` увеличился на 7 дней относительно прежнего.
- [ ] `used_count` `TESTFREE` увеличился.

## Админ: управление и статистика

### 11. Деактивация тарифа

- [ ] Админ → «Тарифы» → деактивировать `Test-30d`.
- [ ] Под пользователем «Купить подписку»: тариф `Test-30d` в списке больше
      не показывается.

### 12. Статистика

- [ ] Админ → «Статистика»: видны корректные агрегаты по платежам
      (сумма Stars, количество транзакций) и по использованию промокодов.

## Scheduler / истечение подписки

### 13. Имитация истечения

- [ ] Остановить бота (`sudo systemctl stop tg-vpn-bot` или Ctrl+C локально).
- [ ] В БД вручную истечь подписку тестового юзера:
  ```sql
  UPDATE subscriptions
     SET expires_at = datetime('now', '-1 hour')
   WHERE user_id = <test_user_id>;
  ```
- [ ] Запустить бота снова.
- [ ] Дождаться прогона expire-job (или сократить интервал в коде/конфиге).
- [ ] Проверить, что в 3x-ui клиент стал `disabled` (через UI панели или
      `GET /panel/api/inbounds/get/<inbound_id>`).
- [ ] Пользователь получил уведомление об истечении подписки в Telegram.
